你的项目

选择原视频，完成球员和比赛片段设置后保存。已有逐拍数据的比赛可打开复盘，不会自动上传或分析。

正在读取…

填写实际比赛日期，年份固定为 4 位；视频上传日期可能与比赛日期不同。

未在视频目录中的文件首次导入需保存一份；已有相同原片会按内容复用。

选择已有原视频：

设置本人位置，或作为旁观者记录比赛。

先选定两位球员都清晰可见的画面。粉色框为 A1，蓝色框为 B1；选择球员标签后在同一画面拖拽对应的框。重新选帧或旋转会清除当前所有球员的框和截图。

比赛片段（可选）

用片段排除中场休息或较长停顿。留空表示使用完整视频，默认近端先发球。

点击时间轴跳转；拖动片段中间移动，拖动左右边缘调整起止时间。也可在下方精确输入秒数。

确认项目

保存球员截图和比赛片段，完成后可继续编辑；保存项目不会启动自动分析或扣费。

填写内容会暂存在当前浏览器；点击最后一步的“保存项目”后，才会保存完整项目到本机服务。
